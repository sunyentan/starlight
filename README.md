# 3D Cellular Automaton - Star Formation Simulation

A visual and interactive 3D cellular automaton built with [Three.js](https://threejs.org/), inspired by the birth of stars in space and concepts from the theory of computing. This project was created as an extra credit project for a computing theory class, [CSE355 @ ASU](https://catalog.apps.asu.edu/catalog/courses/courselist?subject=CSE&catalogNbr=355&term=2251&collapse=N)) and explores how simple rules can lead to complex emergent behavior.

## Overview

This project simulates the growth of a cellular automaton in a 3D environment where points represent emerging "stars." The simulation is contained within a configurable bounding cube, and users can interact with the scene using orbit controls. The automaton's growth, visual appearance, and spatial properties are all adjustable through a control panel.

## Features

- **3D Cellular Automaton:**  
  Points spawn from a seed at the center and propagate in random directions based on adjustable parameters.

- **Dynamic Visual Effects:**  
  - **Color Gradients:** Point colors evolve over time to mimic stellar evolution.

- **Interactive Controls:**  
  Adjust simulation parameters in real time:
  - **Max Cells:** Limit the number of points created.
  - **Point Size:** Change the size of each point.
  - **Step Size:** Control the distance each new point travels.
  - **Cube Size:** Adjust the size of the bounding container.
  - **Point Shape:** Choose between circle, square, or triangle textures.

- **Orbit Controls:**  
  Use mouse or touch interactions to explore the 3D environment from any angle.
